# Alarm sound collection

These ten recordings were selected by the user from Freesound. They are existing
creator-uploaded sounds, not generated for this project. Each source page was
checked for CC0 1.0 before downloading its publicly available high-quality MP3
preview. The full-resolution source WAV/OGG is not claimed to be included.

`catalog.json` records the creator, source page, download URL, CC0 license link,
and SHA-256 checksum of each bundled file. The same files are bundled as Android
raw resources. Run `node scripts/fetch-alarm-sounds.cjs` to refresh them after
checking the source licenses. No runtime download is used.

CC0 dedication: https://creativecommons.org/publicdomain/zero/1.0/

User-imported audio stays private in app storage and is not part of this collection.
